Static TTFs for the share images (`/api/og`; Satori can't read WOFF2 or variable fonts).

- Bricolage Grotesque, weight 800, optical size 96 (Google Fonts, SIL Open Font License 1.1)
- JetBrains Mono, weight 700 (Google Fonts, SIL Open Font License 1.1)

The site itself loads the fonts with `next/font` (app/fonts.ts).
